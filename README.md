## Events Management
Description

A full-stack web application for managing events. Users can create 
and manage their own events, join events, and track their participation.

Tech Stack
React 19
TypeScript
Vite
Fastify
PostgreSQL
TypeORM
Zustand
Tailwind CSS
shadcn/ui
JWT
Zod
Argon2

Features

User registration and JWT authentication
View all events and detailed event pages
Create, edit, and delete events
Owner permission checks
Join and leave events
“My Events” section with created and joined events
Event capacity and participation statistics
Form validation with Zod
Secure password hashing with Argon2
REST API with Fastify and PostgreSQL
